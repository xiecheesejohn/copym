# copym Symbols

`copym-symbols.ttf` (3 KB) holds only the key symbols the popup shows
(⌘ ⇧ ⌥ ⌃ ⏎ ↵ ⌫ ⌦ ⎋ ⇥ ⌄ ← ↑ → ↓ · …). System fonts on macOS lack some of them,
which egui rendered as boxes.

It is a subset of Adwaita Sans 50.0 (Regular, wght 400, opsz 14), renamed;
SIL Open Font License 1.1, see `copym-symbols-OFL.txt`.
